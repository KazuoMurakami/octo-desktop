# Nome e logotipo

O código do Octo é livre sob a [licença MIT](LICENSE). **O nome "Octo" e o logotipo do polvo não estão incluídos nessa licença**: pertencem ao autor do projeto ([@KazuoMurakami](https://github.com/KazuoMurakami)), com todos os direitos reservados.

Isso vale para `src/assets/octo-logo.png`, `src/assets/octo-mark.png`, `public/favicon.png` e `build/icon.png`.

- Usar o nome e o logo para falar do Octo (artigos, tutoriais, vídeos, links para este repositório) é bem-vindo.
- Forks e distribuições modificadas devem usar outro nome e outro logotipo.
