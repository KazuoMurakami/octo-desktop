## Como tirar

- Use dados fictícios: um workspace de exemplo (como `loja/` com `loja-api` e `loja-web`), sem nomes de clientes, e-mails ou caminhos pessoais. Rode o Octo com uma pasta de dados separada (`OCTO_DATA_DIR=/tmp/octo-demo npm run desktop`) para não expor os seus dados reais. Com outra pasta de dados, essa janela abre à parte, mesmo com o Octo instalado aberto.
- Janela em torno de 1440×900, sem zoom, no tema padrão. Nas duas imagens de "Como funciona", recorte só o painel ou o diálogo, para continuarem legíveis em meia largura.
- Salve como PNG, de preferência abaixo de 500 KB cada (passe por um otimizador como o `oxipng` ou o TinyPNG).
- Confira o texto alternativo (`alt`) no README se o conteúdo da imagem mudar.
